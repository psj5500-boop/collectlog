콜렉트로그 개인정보처리방침

시행일: 2026년 7월 10일

콜렉트로그(CollectLog)는 사용자가 소장한 도서, DVD, Blu-ray 등의 미디어 정보를 기록하고 관리할 수 있도록 돕는 앱입니다. 이 개인정보처리방침은 콜렉트로그가 어떤 정보를 사용하고, 그 정보를 어떤 목적으로 처리하는지 설명합니다.

1. 수집하거나 사용하는 정보

  • 카메라 권한: 바코드를 스캔하기 위해 사용합니다. 카메라 영상은 앱 서버에 저장하거나 전송하지 않습니다.
  • 바코드 및 ISBN 정보: 도서와 영상 정보를 검색하기 위해 사용합니다.
  • 미디어 정보: 제목, 저자 또는 감독, 표지 이미지 주소, ISBN 또는 바코드 번호, 미디어 유형, DVD/Blu-ray 형식 정보를 저장합니다.
  • 사용자가 직접 입력한 정보: 구입일과 메모를 기기 내부에 저장합니다.
  • 백업 파일 정보: 사용자가 백업 내보내기를 실행하면 컬렉션 정보, 구입일, 메모가 포함된 JSON 백업 파일이 생성될 수 있습니다.
  • 인터넷 연결: 알라딘 상품 검색 API, 국립중앙도서관 ISBN API 호출 및 표지 이미지 표시를 위해 사용합니다.
  • 광고 관련 정보: Google AdMob 광고 제공을 위해 광고 식별자, 기기 정보, 광고 노출 및 상호작용 정보가 사용될 수 있습니다.

2. 정보 사용 목적

  • 바코드 스캔을 통한 미디어 정보 검색
  • 사용자의 소장 목록 저장 및 표시
  • 구입일과 메모 기록
  • 도서, 영상, DVD, Blu-ray 분류 표시
  • 표지 이미지 표시
  • 앱 내 광고 표시 및 광고 성과 측정
  • 백업 파일 생성 및 사용자가 선택한 위치로 공유 또는 저장

3. 외부 서비스 제공자

콜렉트로그는 미디어 정보를 검색하기 위해 알라딘 상품 검색 API와 국립중앙도서관 ISBN API를 사용할 수 있습니다. 앱은 사용자가 스캔하거나 입력한 바코드 또는 ISBN 값을 위 서비스에 요청할 수 있습니다. 각 외부 서비스의 데이터 처리 방식은 해당 서비스의 정책을 따릅니다.

4. 기기 내 저장

사용자가 저장한 컬렉션 정보, 구입일, 메모는 현재 사용자의 기기 내부 데이터베이스에 저장됩니다. 콜렉트로그는 별도의 자체 서버에 사용자의 컬렉션 정보를 저장하지 않습니다.

앱을 삭제하거나 기기 데이터가 초기화되면 저장된 정보가 삭제될 수 있습니다.

사용자가 백업 내보내기 기능을 사용하는 경우, 컬렉션 정보가 포함된 백업 파일이 생성됩니다. 이 백업 파일의 저장 위치, 공유 대상, 보관 여부는 사용자가 선택하며, 백업 파일을 외부 앱이나 클라우드 서비스에 저장하는 경우 해당 서비스의 정책이 적용될 수 있습니다.

5. 광고 및 분석 도구

현재 버전의 콜렉트로그에는 Google AdMob 광고 SDK가 포함되어 있습니다. Google AdMob은 광고 제공, 광고 성과 측정, 부정 사용 방지 등을 위해 광고 식별자, 기기 정보, IP 주소, 광고 노출 및 상호작용 정보 등을 사용할 수 있습니다.

광고 데이터 처리 방식은 Google의 정책을 따릅니다. 사용자는 기기 설정에서 광고 개인 최적화 또는 광고 식별자 관련 설정을 조정할 수 있습니다. 향후 지역별 법령에 따라 필요한 경우 광고 동의 절차를 추가합니다.

6. 정보 보관 및 삭제

사용자가 앱에서 항목을 삭제하면 해당 항목의 저장 정보가 기기 내부 데이터베이스에서 삭제됩니다. 앱을 삭제하면 앱 데이터도 함께 삭제될 수 있습니다.

7. 아동의 개인정보

콜렉트로그는 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 보호자가 아동의 정보 처리와 관련해 문의할 경우 아래 연락처로 문의할 수 있습니다.

8. 개인정보처리방침 변경

앱 기능, 외부 서비스, 광고 또는 분석 도구가 변경되는 경우 개인정보처리방침이 업데이트될 수 있습니다. 변경 시 앱 또는 스토어 등록 정보 등을 통해 최신 내용을 안내합니다.
